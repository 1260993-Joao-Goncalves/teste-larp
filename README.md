# Uni!Study — Projeto LAPR1 DAB01

## Publicar no GitHub Pages

1. Extrai esta pasta.
2. Coloca **todo o conteúdo desta pasta** na raiz do repositório GitHub (não coloques a pasta `UniStudy-GitHub` dentro do repositório).
3. Confirma que `index.html` fica na raiz e que a pasta `css` contém `style.css`.
4. Faz commit/push e aguarda a atualização do GitHub Pages.

## Estrutura

- `index.html` — página principal.
- `css/style.css` — estilos do site.
- `images/` — pasta reservada para imagens/fotografias da equipa.
- `Documents/` — pasta reservada para documentos do projeto.

As fotografias dos elementos da equipa e o relatório PDF original não foram fornecidos nesta conversa. Os cartões da equipa usam iniciais até serem adicionadas fotografias. Se quiseres publicar o relatório, coloca o ficheiro `Relatorio_Sprint1.pdf` dentro de `Documents/` e adiciona o respetivo link no HTML.

O site utiliza Google Fonts através de uma ligação externa; se não houver ligação à Internet, serão usadas fontes alternativas locais do sistema.
